# P vs NP: formal proof research

This repository contains Lean 4 formal proofs for restricted models and conditional complexity statements, alongside Rust experiments.

**Scope:** No claim to settle P versus NP. The main open step is a superpolynomial SAT lower bound for unrestricted computation; restricted black-box bounds cannot supply it directly.

Proofs and Rust tests are validated by GitHub Actions. See the workflow status before treating them as kernel-checked.
